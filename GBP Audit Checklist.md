# Google Business Profile Audit Checklist

An interactive, client-ready checklist I use to audit every new Google Business Profile before starting optimization work, covering profile basics, trust signals, reviews, citations, content, technical/local SEO, and AI/LLM visibility (ChatGPT, Gemini, AI Overviews).

## Live tool

Once GitHub Pages is enabled on this repo: `https://laiba-khan3.github.io/gbp-audit/`

## What's in this repo

- `index.html`: the interactive checklist (single file, no build step). Click items to check them off, see live progress, and print/save as a PDF to send to clients.

## Why this exists

Part of my local SEO toolkit: a repeatable process I run for every new client, rather than a mental checklist that changes each time.
